AI sounds like

A .idiomark file captures how a person speaks and thinks — voice, tone, writing patterns, values, cognitive style — so AI systems can sound like that person and understand them, instead of sounding generic.

Read the spec How it works
§1 · why

Models generate beige.

Prompting for a persona every time doesn't scale and doesn't travel — what works on one model drifts on another. A .idiomark file is a durable, versioned, portable personality profile that any system can consume. One file. Every model. Still you.

§2 · format

Write it once. Carry it everywhere.

  1. 01

    Describe

    Capture voice, tone, writing patterns, values and cognitive style in plain, human-readable INI. No lock-in, no black box.

  2. 02

    Validate

    The loader and validator check your profile against the stable v1 schema — v2 features ship experimentally alongside, never breaking readers.

  3. 03

    Apply

    Hand the file to any consumer — SDK, CLI, MCP server, inference layer — and responses come back sounding like the person it describes.
